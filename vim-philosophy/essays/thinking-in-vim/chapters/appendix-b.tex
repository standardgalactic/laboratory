\chapter{Every Ex Command}
\label{app:ex}

Every Ex command covered in this book, in the form typed on the command line (a leading \texttt{:} is implied throughout and omitted from the table for brevity). Ranges, where a command accepts one, follow the syntax of Chapter~\ref{ch:ex} and are omitted from the Command column unless a specific range usage is idiomatic enough to be worth showing directly.
