\chapter{Every Option}
\label{app:options}

Every option named in this book, set with \texttt{:set} per Chapter~\ref{ch:installing}'s syntax. Boolean options are toggled with \texttt{set} \textit{option} / \texttt{set no}\textit{option}; value options are set with \texttt{set} \textit{option}\texttt{=}\textit{value}.
