# Canonical Principles

These are working commitments, not universal truths. A project may challenge them, but it must say so explicitly.

1. Objects are useful compressions of trajectories rather than metaphysically primitive substances.
2. A state is intelligible through the continuations it permits and excludes.
3. Repair preserves difference rather than erasing history.
4. A detected fault does not automatically license intervention.
5. Admissibility and repair warrant are distinct.
6. Persistent histories make revision inspectable.
7. Representation is an active constraint on what can be diagnosed.
8. A system should preserve enough structure to explain how its present state became reachable.
9. Optimization without admissibility can produce locally efficient but structurally destructive outcomes.
10. When no admissible reference class exists, repair must escalate into revision of the representational scheme.
