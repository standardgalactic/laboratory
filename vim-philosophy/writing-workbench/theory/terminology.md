# Terminology and Notation Rules

The model must preserve established terminology unless the project explicitly introduces a revision.

For every newly introduced technical term, record:

- the exact term;
- a one-sentence definition;
- its relation to existing concepts;
- whether it is descriptive, normative, formal, or metaphorical;
- the first file and section where it appears.

For every mathematical symbol, record:

- symbol;
- meaning;
- domain and codomain if applicable;
- units where applicable;
- dependencies;
- first appearance;
- later reuse.

Do not use these distinctions interchangeably:

- detection versus repair;
- admissibility versus constraint satisfaction;
- structural fidelity versus semantic equivalence;
- verification success versus repair warrant;
- state versus trajectory;
- history preservation versus duplication;
- compression versus deletion.
